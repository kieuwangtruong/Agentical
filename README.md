# Agentical — DataMate Challenge 2026

**Team Agentical** | Zalo AI Challenge 2026 — DataMate: Talking To Your Data Through Agentic AI

## 🎯 Goal
Build a high Penalized-Accuracy, offline, deterministic-first Natural Language to SQL & Tabular Reasoning Agent for Vietnamese business data.

- **Offline Inference**: 100% air-gapped, no external APIs.
- **Resource Constraints**: Total model parameters $\le$ 15B.
- **Strict Scoring**: Penalized Accuracy $= \frac{\text{Correct} - \text{Incorrect}}{\text{Total}}$.
